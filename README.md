# Dheeraj Sankhla — Portfolio & DigitalWeb Platform

High-performance personal portfolio and resume web application for **Dheeraj Sankhla**, featuring Full-Stack Engineering, Generative AI & MCP Architectures, E-Commerce Storefronts, and Performance Marketing (Meta Ads).

## Development

Run the dev server locally:

```sh
npm install
npm run dev
```

The application will launch at `http://localhost:3030`.

## Built With

- TanStack Start & TanStack Router
- TypeScript & React 19
- Tailwind CSS v4 & Lucide Icons
- Framer Motion / Motion & Radix UI
